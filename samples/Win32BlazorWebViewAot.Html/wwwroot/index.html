Call into .NET

These buttons leave the page and run C# in DotNetBridge.cs through DotNet.invokeMethodAsync. Even the machine name — a synchronous C# method — comes back as a promise: the synchronous DotNet.invokeMethod is not implemented on this channel. The clock above keeps ticking while a call is in flight, which is the point.
